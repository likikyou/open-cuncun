# Support

Thank you for using Cuncun Core.

## Questions and setup help

Use [GitHub Discussions](https://github.com/likikyou/open-cuncun/discussions) for setup
questions, deployment advice, and ideas that are not yet concrete bug reports. Include
your operating system, Python version, installation method, and the relevant provider or
Feishu integration. Remove credentials, user messages, private prompts, and personal data.

## Bug reports and feature requests

Use the repository's [Issue templates](https://github.com/likikyou/open-cuncun/issues/new/choose)
for reproducible bugs and scoped feature proposals. Please search existing Issues first.

## Security vulnerabilities

Do not report security vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md) and
email `likikyou999@gmail.com`.

Support is provided on a best-effort basis by project maintainers and community members.
